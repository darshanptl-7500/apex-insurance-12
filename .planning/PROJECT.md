# Apex Insurance — Project Overview

> Generated by `/rapidx:onboard-codebase`. This is a living document — keep it in sync as the project evolves.

## What this is

Apex Insurance is a demo/training reimplementation of a London Market-style **Underwriting (UW) Workbench** — a single "pane of glass" for underwriters that unifies:

- **Pipeline** — Upcoming / Bound / NTU-Declined / DA / Day File / Queries buckets
- **New Risk / Submission intake**
- **Underwriter's File** — hierarchical Policy → Section workbench (Limits, Premiums, Performance, Bureau, Deductions, Outwards RI)
- **Quotes → Bind → Policy**
- **Claims** (read-side KPIs: ILR, CAP)
- **Documents** (DM22-style upload/preview)
- **Activity Log / Workflow tasks** (Data Entry, Second Sight, Front Sheet, Modelling, Referral, Wording)
- **Associations/Connect** — broker/insured CRM-lite
- **Reporting/MI**

It explicitly is **not** the system of record for policy administration — that role is played by a stubbed "Open Box" legacy system. Workbench edits post to Open Box and the display refreshes from a replica; this integration is deliberately faked (`ApexInsurance.Data.OpenBox`), not a real downstream system. See `docs/UW-SOLUTION-MAP.md` for the explicit in/out-of-scope integration list (Open Box SOAP, DM22, Dynamics CRM, Lloyd's/DXC, AD are all stubbed).

## Solution layering (`src/`)

Clean, acyclic layering — no back-references detected:

```
ApexInsurance.Domain          (root — plain entities/enums, zero deps)
  ├── ApexInsurance.Data              (EF Core DbContext + repositories)
  ├── ApexInsurance.Dto               (shared DTOs)
  ├── ApexInsurance.UI                (ViewModel/presentation mapping)
  └── ApexInsurance.Security          (demo token issuer/validator)
        ApexInsurance.Data.OpenBox    (Data + Domain — stub legacy PAS gateway/bus)
        ApexInsurance.Services.Contracts  (Dto + Domain — one folder per business module)
              ApexInsurance.Services  (Domain, Data, Services.Contracts, Dto, Data.OpenBox, Security, Shared)
                    ApexInsurance.Api (top — references everything; controllers, RabbitMQ hosted consumers, DI wiring)
ApexInsurance.Shared           (cross-cutting helpers)
```

| Project | Purpose |
|---|---|
| `ApexInsurance.Api` | Web host: controllers, `Program.cs`, RabbitMQ hosted consumers |
| `ApexInsurance.Domain` | Entities/enums (Submission, Quote, Policy, Claim, Endorsement, Broker, Insured, AuthorityRule, ReferralRule, RateTable, RiskAnswer, AuditLog, User, …) |
| `ApexInsurance.Data` | EF Core `ApexInsuranceDbContext` + repositories (UnitOfWork-style) |
| `ApexInsurance.Data.OpenBox` | Stub "Open Box" legacy PAS gateway (`LocalOpenBoxGateway`) + integration bus (`OpenBoxIntegrationBus`) — **not a real integration** |
| `ApexInsurance.Dto` | Shared DTOs (namespace kept as `ApexInsurance.Services.Dto`) |
| `ApexInsurance.Services.Contracts` | Service interfaces (Pipeline, Rating, Authority, Workbench, Workflow) |
| `ApexInsurance.Services` | Service implementations (Auth, Rating, Admin, Support) |
| `ApexInsurance.Security` | `DemoTokenService` — demo-only bearer token issuer, **not production auth** (see RISKS.md) |
| `ApexInsurance.Shared` | Cross-cutting helpers |
| `ApexInsurance.UI` | ViewModel mapping layer |

## Frontend layout (`web/`)

- `apex-ng8/` — Angular 8.2.14 CLI project; feature folders under `src/app/features/{dashboard,case-hub,modelling,reporting,admin,login}`
- `apex-shell/` — legacy AngularJS host (`app/{controllers,directives,services,views}`) that also receives the built `apex-ng8` bundle under its `ng8/` subfolder
- `serve-hybrid.js` — single-origin static host; routes `/ng8*` to the Angular 8 bundle (SPA fallback), everything else to the AngularJS shell (hashbang routing), no HTTP caching (dev host)
